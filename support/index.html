Support

Common questions

I'm not getting reminders

Reminders are off by default. Turn them on for a game (Games → game → Reminders), for a server, for a single event, or for everything in Settings → "Remind me by default". Then check Settings → Notifications says "Allowed". If it says "Turned off", tap it to open iOS Settings and allow notifications for Next Reset.

Why does Settings say "Scheduled 60 of 64"?

iOS lets an app hold at most 64 pending reminders. Next Reset always keeps the soonest ones scheduled and refills them every time you open the app, edit something, or iOS gives the app background time. If you have many reminders a day, open the app at least once every day or two to keep them topped up.

Should I use a UTC offset or a city for my server?

Use the UTC offset most games publish (for example "server time UTC+8"). A fixed offset never moves. Pick a city or region only if the game's server follows daylight saving time; the clock then shifts automatically twice a year.

One event happens on several servers at different times

Add each server to the game, then set the event to "All servers". It fires at the same server time on each server's own clock, for example a 05:00 daily reset on both EU and Asia.

How do I move my data to a new iPhone?

Settings → Export backup… and save the file to iCloud Drive or Files. On the new iPhone, install Next Reset and use Settings → Import backup…. Choose "Merge" to keep anything already there, or "Replace" to start fresh.

Does the app need an internet connection or an account?

No. Next Reset works fully offline, has no account and never sends your data anywhere. See the privacy policy.
